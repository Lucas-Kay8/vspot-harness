# Contributing to VSPOT Harness

Thank you for your interest in contributing! VSPOT Harness is transitioning from a Markdown-based conceptual template repository into a CLI-driven machine-readable policy engine. 

## Contribution Areas

We welcome contributions in the following areas:
- JSON Schema definitions (`schemas/`)
- CLI Tool scaffolding and logic (`src/cli/`, coming soon)
- Platform Adapters (e.g., Cursor, Claude Code)
- Examples and Integration Tests

## Principles

All contributions should support the core goal:
> Make AI agent execution safer, more verifiable, and more auditable through deterministic, machine-readable policies.

## Pull Request Requirements

Before submitting a PR, please ensure:
- [ ] You have run schema validations on any updated `.yaml` or `.json` files.
- [ ] Your code passes the unit tests (once established).
- [ ] You adhere to the principle of "Hard Enforcement over Soft Constraints".
- [ ] Documentation is updated if needed.
