# Story Readiness Check Command (故事就绪检查指令)

## 🎯 目的 (Purpose)
This check ensures a story is ready for AI agent execution.
此检查可确保故事已准备好供 AI 智能体执行。

## 📋 检查单 (Checklist)
- [ ] Story title is clear (故事标题清晰)
- [ ] Business goal is clear (业务目标清晰)
- [ ] User value is clear (用户价值清晰)
- [ ] Acceptance criteria are explicit (验收标准明确)
- [ ] Technical context is provided (提供了技术上下文)
- [ ] Relevant architecture links are included (包含了相关架构文档的链接)
- [ ] Dependencies are identified (明确了依赖项)
- [ ] Files likely to change are listed (列出了可能发生更改的文件)
- [ ] Files out of scope are listed (列出了范围外的文件)
- [ ] Test expectations are defined (定义了测试预期)
- [ ] Risk level is assigned (分配了风险级别)
- [ ] Human approval needs are identified (确定了人工审批的需求)

## 🛑 视为未就绪的情况 (Story Is Not Ready If)
- acceptance criteria are vague (验收标准模糊)
- scope is too broad (范围过于宽泛)
- architecture is missing (缺少架构设计)
- required data is unavailable (所需数据不可用)
- high-risk changes are hidden (高风险更改被隐藏)
- test expectations are missing (缺少测试预期)

## 📝 输出格式 (Output Format)
```text
Story Readiness: Ready / Not Ready (故事就绪状态: 就绪 / 未就绪)

Missing Information (缺失信息):
- 

Risks (风险):
- 

Recommended Next Step (推荐的下一步操作):
- 
```
